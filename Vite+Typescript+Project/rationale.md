## Rationale

TypeScript improved code quality in this project by making state and event logic explicit before runtime. Defining `Vibe`, `Filter`, and `Task` types clarified valid values and object shape, which reduced ambiguity while building task filtering and UI updates. Type-checked DOM queries also made the code safer: the app verifies required elements exist before binding events, so null-related issues are handled early instead of failing unpredictably in the browser. In addition, typed function signatures made refactoring easier when rendering logic changed from string-based updates to DOM node creation.

Project structure was intentionally simple: `main.ts` acts as the entry point and UI shell setup, while `counter.ts` contains interactive behavior and state transitions. This separation keeps startup concerns and feature logic independent, so future contributors can modify behavior without touching bootstrap code. The module boundary uses import/export in a straightforward way: one exported setup function initializes the feature from the entry file, keeping coupling low and responsibilities clear.

Vite’s workflow significantly improved development speed. The dev server provided instant feedback and hot updates during iteration, which made UI and interaction tuning quick. The build pipeline combined TypeScript checks and production bundling in one command, giving confidence that code is both type-safe and deployable. This reduced context switching and encouraged frequent validation during implementation.

Several JavaScript patterns were especially useful. Array methods (`map`, `filter`, `forEach`) made task operations expressive and concise for rendering, toggling status, and deleting items. Spread syntax supported immutable-style updates when replacing tasks, which kept state transitions predictable. Closures captured local app state (tasks, current filter, selected vibe) without exposing globals, making behavior easier to reason about. Destructuring was less central here, but remains valuable for cleaner extraction of object values in future feature growth.
